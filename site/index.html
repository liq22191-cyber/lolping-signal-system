lolPing GitHub

League pings for your whole desktop

Hold Alt, drag, and let go on a ping. lolPing pops the animation and plays the sound from the Rift on top of any app, on any monitor. Friends watching your screen share see it too.

Download for Windows Source on GitHub

Version 0.1.0 for Windows 11, 64-bit. Free and open source.

Eight pings, same as the Rift

The wheel follows League’s order, starting at the top and going clockwise. Select one to see its animation.

    Alt + click can also drop a basic ping. It’s off by default so ordinary Alt + click shortcuts keep working.

    Made for the desktop

    Every app, every monitor
    The wheel opens under your cursor over browsers, editors, chat apps and the desktop itself, on every screen, at every display scale.
    Shows up when you share
    Pings are drawn in a real window, so whole-screen capture in Discord, OBS and screenshot tools records them.
    Your trigger, your shortcut
    Alt by default. Switch to Ctrl, Shift, Win, Caps Lock, a side mouse button or any other key, and pick the shortcut that turns pinging off and on.
    Out of the way
    A normal Alt + click still reaches the app under it. Ctrl + Alt + P pauses pinging, and the tray icon shows whether it’s on.
    The look and sound you know
    The icons, animations and sounds follow League’s ping wheel, All In clash included.
    Small and offline
    No account and no telemetry. Settings live in a small file, and it can start with Windows.

    Install

    1. Download lolPing-Setup-0.1.0.exe from the latest release.
    2. Run it. The installer isn’t code-signed, so Windows SmartScreen may stop it: select More info, then Run anyway.
    3. lolPing opens its settings and moves to the tray. Hold Alt and drag anywhere to ping.

    Questions

    Does it work inside League?

    lolPing is a desktop overlay. It doesn’t read, change or hook into the game. Use the game’s own pings in a match; exclusive-fullscreen games draw over the overlay anyway.

    Why does Windows or my antivirus warn about it?

    The installer isn’t signed with a paid certificate, and lolPing watches the mouse and keyboard to catch Alt + drag, using the same low-level hook that hotkey tools use. All of the source is on GitHub if you’d rather build it yourself.

    My friends can’t see the pings on Discord.

    Share your entire screen instead of a single window. Window capture records only that window, and pings live in their own overlay window.

    Alt + drag does nothing over some windows.

    Windows hides input aimed at programs running as administrator, such as Task Manager, from normal apps. Over those windows the wheel won’t open.

    How do I pause, quit or uninstall it?

    Ctrl + Alt + P pauses and resumes pinging. Right-click the tray icon to quit. To remove it, open Windows Settings, then Apps, then Installed apps.
